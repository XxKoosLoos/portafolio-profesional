# Portafolio de Cristian Antonio Concha Reyes

Portafolio estático y sin dependencias de construcción. Archivos del sitio en `dist/`. Repositorio: https://github.com/XxKoosLoos/portafolio-profesional.

## Consulta local

Abrir `dist/index.html` en un navegador. También puede servirse la carpeta `dist/` con un servidor estático local.

## Alcance

Diseño cyberpunk oscuro con cian y magenta neón, paneles angulares, retícula técnica y detalles de terminal. Incluye navegación por anclas, adaptación mediante CSS, dos casos de estudio, un ejercicio de Git y enlaces de contacto a GitHub. Los apartados desplegables usan HTML nativo y no requieren JavaScript. La identidad visual se define en `dist/cyberpunk.css`, sobre la estructura de `dist/styles.css`. Los efectos luminosos son estáticos, sin parpadeos ni animaciones.

El esquema del encabezado es un mapa conceptual de áreas de trabajo; no es una captura ni una prueba de integración de hardware.

El propietario creó el repositorio para alojar este código. No se ha desplegado el sitio web. Por confirmación del propietario, asistencias, puertas ESP32, Mi Pastillero, trabajos web y CAD se presentan primero como actividades fuera de la escuela. Sus muestras y fuentes siguen pendientes. Los casos académicos y el ejercicio de Git aparecen después. No se añadieron formularios, analítica ni servicios externos.

## Validación

Se comprobaron el idioma del documento, la ausencia de IDs duplicados, los destinos internos y recursos locales y el equilibrio de delimitadores CSS. La sección CAD y sus identificadores SVG también se revisaron mediante análisis del HTML. No se verificó la respuesta HTTP de las URLs externas en esta comprobación.

Las cuatro combinaciones principales del tema cyberpunk medidas superan 4,5:1: texto principal 18,09:1, texto secundario sobre superficie 9,51:1, cian sobre fondo 14,93:1 y magenta sobre superficie 8,41:1. Esto no constituye una auditoría completa de accesibilidad.

La herramienta de navegador requerida por el entorno Sites no está disponible; no se inició servidor de vista previa ni se realizaron capturas.

## Antes de publicar

La sección CAD incorpora SolidWorks y AutoCAD a petición del propietario. Sus diagramas SVG son ilustraciones conceptuales, no capturas de trabajos. Faltan los modelos, planos o imágenes reales, con descripción y autorización de publicación.

Revisar texto biográfico y contribuciones individuales; validar visualmente en móvil y escritorio y probar navegación por teclado. Seleccionar alojamiento y revisar el resultado concreto antes de autorizar su publicación.
